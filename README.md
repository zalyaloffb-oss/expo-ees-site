# Сайт «ИвентЭкспоСервис»

Публичная версия: https://zalyaloffb-oss.github.io/expo-ees-site/

## Работа с телефона

Открыть браузерный редактор:

https://github.dev/zalyaloffb-oss/expo-ees-site

1. Войдите в GitHub под аккаунтом `zalyaloffb-oss`.
2. Откройте нужный файл в левой колонке.
3. Внесите изменение.
4. Откройте раздел **Source Control**.
5. Напишите краткое описание изменения и нажмите **Commit & Push**.
6. GitHub Pages автоматически обновит сайт через несколько минут.

Компьютер и локальный сервер для этого не нужны.

## Основные файлы

- `index.html` — главная страница, которая открывается по публичной ссылке.
- `expo-ees-neon-concept.html` — рабочая копия главной страницы.
- `expo-ees-neon-style.css` — оформление всего сайта.
- `expo-ees-neon-script.js` — поведение главной страницы.
- `service-page.html` и `service-page.js` — страницы услуг, портфолио и статей.
- `mobile-header.js` — закреплённая мобильная панель с логотипом и поиском.
- `assets/` — изображения и графика.

## Небольшие текстовые изменения

Для быстрой правки отдельного файла можно открыть его на GitHub, нажать значок карандаша, изменить текст и выбрать **Commit changes**. После сохранения публикация запускается автоматически.

## Добавление изображений с телефона

1. Откройте нужную папку внутри `assets` на обычной странице GitHub.
2. Нажмите **Add file → Upload files**.
3. Выберите изображение на телефоне и сохраните через **Commit changes**.
4. Укажите путь к изображению в HTML или JavaScript без пробелов и русских букв в имени файла.

## Важно

- Главная страница хранится в двух файлах: `index.html` и `expo-ees-neon-concept.html`. При изменении структуры главной страницы нужно обновлять оба файла одинаково.
- Не удаляйте папку `assets` и файл `.nojekyll`.
- Перед крупными изменениями лучше сначала создать отдельную ветку или попросить Codex выполнить изменение и проверить мобильную версию.
